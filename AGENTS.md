# AGENTS.md — правила проекта clear-goal-skill

## Назначение проекта
Глобальный навык OpenCode для формулирования целей AI-агентов. Публикуется на GitHub как open-source skill.

## Роль AI-агента в этом проекте
- Редактировать SKILL.md, README.md, документацию
- Готовить релизы и теги
- Не выполнять рабочую логику навыка — только развивать инструмент

## Запреты
- Не изменять логику SMART+STRONG без согласования
- Не коммитить личные SSH-ключи или токены
- Не использовать системный temp (`C:\Users\...\AppData\Local\Temp`) — только `temp/` в корне проекта
- Удаление только в корзину (Recycle Bin)

## Процесс
1. Изменения в `SKILL.md` → тест через `/цель` и `/goalhelp`
2. Изменения в `README.md` → актуализировать install instructions
3. Релиз: tag `v1.x.x`, CHANGELOG.md

## Структура
```
clear-goal-skill/
├── SKILL.md          # Основной навык (инструкции для агента)
├── README.md         # Документация для GitHub
├── LICENSE           # MIT
└── temp/             # Промежуточные файлы
```

## Ключевые файлы
- `SKILL.md` — алгоритм работы, критерии SMART+STRONG, примеры
- `README.md` — описание, установка, отличия от аналогов
